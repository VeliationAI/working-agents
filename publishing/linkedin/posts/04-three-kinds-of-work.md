Sort the work before you pick a tool. Most agent projects are the wrong shape, and the workflow would have been the better machine.

Three kinds.

Transform. You already have the material. Summarize, reformat, extract the fields. The path is known. Build a workflow and run it the same way every time.

Find and compose. You know the shape of the answer and you do not yet have the material. Meeting prep. A vendor comparison from their own docs. Why a metric moved. This is the sweet spot for a read-only agent with a tight brief and a source rule.

Change the world. Send, pay, merge, delete, reply to a customer. Drafts and approvals. A person performs the change. You graduate one write action at a time, after the drafts have been dull and correct.

And a fourth that should not be given a finish line the loop is allowed to cross: judgment. Should we fire the vendor? Is this message kind enough? The agent can gather the facts. The decision stays with a person.

Watch the next demo with this sort in mind. A workflow in an agent costume can still be worth buying. Call it what it is, and keep the write tools away from it.
