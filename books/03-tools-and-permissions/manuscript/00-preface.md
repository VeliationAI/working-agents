This book is about what a loop is allowed to touch.

In Book 1, The Agent Loop, a tool was defined as a function the loop is allowed to call. In Book 2, Briefing an Agent, the BOUNDARIES section of the brief named which tools a job may use. This book goes one level down. It is about how that sentence in the brief becomes true in the system, so that "do not send" is a fact about the tool list and not a hope about the model's manners.

The central idea is small. A loop can only do what its tools let it do. If you want it to be trustworthy, you do not need to make the model better behaved. You need to make the tools narrower, the approvals real, the secrets absent, and the log complete.

Working Agents is a free series of field guides. Each book is meant to be read in an evening and heard on a commute. The PDF and the audio carry the same words. You can read this book without the others. The terms at the back define the words you will need.

## Who this is for

If you use an agent at work, this book tells you what to ask before you connect it to your inbox, your files, or your accounts. If you buy or supervise agents, it gives you a list of questions that vendors can answer in plain language. If you build them, it gives you a tool list you can defend in a review.

You do not need to write code to follow it. When a chapter describes something an engineer would do, it also says what you can ask for if you are not the engineer.

## What you will have at the end

- A tool list for one real job, sorted into read, draft, and write.
- A short argument for each tool that is on it, and a reason for each one that is not.
- A place in the loop where a person approves, and a record of what they were shown.
- A separation between the loop and the secrets it must never see.
- A log that lets you reconstruct, on Monday, exactly what happened on Friday.

## How to read it

Keep one job in front of you. If you wrote a brief in Book 2, use that one. Each chapter ends with something you can do to the job's tool list. Small changes, made in order, are the whole method.
